# Price Tracker

**Маркетплейсы убрали публичную историю цен. Я её вернул.**

## Что умеет

- **Своя история цен.** Одна кнопка, и цена с датой в вашей базе. График строится сам.
- **Целевая цена.** Задали сумму, и товар подсветится, когда цена до неё дойдёт. (Скоро: уведомления в Telegram.)
- **Три магазина.** Wildberries, Ozon, Л'Этуаль. Список будет расти.
- **Всё локально.** Никакого облака, аккаунтов и слежки.

## Как устроено

| Часть | Что делает |
|---|---|
| Расширение для браузера | Берёт название, ссылку и цену со страницы товара, показывает список и график |
| Локальный сервер | Хранит товары и историю, отдаёт через API на `http://localhost:8080/api` |  

## Установка

**1. Запустите сервер**

```bash
# замените на команду запуска вашего бэкенда
./mvnw spring-boot:run
```

Порт `8080`. В базе должны быть магазины с типами `WILDBERRIES`, `OZON`, `LETU`.

**2. Установите расширение**

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика**.
3. **Загрузить распакованное расширение**, выберите папку проекта.

**3. Пользуйтесь**

Откройте товар, нажмите иконку расширения, затем **Добавить товар с открытой страницы**. Повторное нажатие запишет новую цену в историю.

## Ограничения

- Трекер знает только цены, которые записали вы. Начинайте сегодня.
- Цена зависит от региона, аккаунта и времени. Фиксируется то, что увидели вы.
- Магазины меняют вёрстку. Парсер сломался, значит, откройте issue.
- Проект не связан с магазинами.
