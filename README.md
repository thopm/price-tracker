# Price Tracker
Маркетплейсы убрали публичную историю цен. Я ее вернул.
## Что умеет

- **Собственная история цен.** Открыли товар, нажали одну кнопку, и цена с датой записались в вашу базу. Дальше график строится сам.
- **Целевая цена.** Задали сумму, до которой готовы ждать. Когда цена опускается до неё, товар подсвечивается как достигший цели. (в будущем отправляет сообщение в телеграмм)
- **Три магазина.** Wildberries, Ozon, Л'Этуаль. (список будет пополняться)
- **Всё локально.** Данные лежат у вас. Никакого облака, аккаунтов и «аналитики».

## Как устроено

Проект состоит из двух частей:

| Часть | Что делает |
|---|---|
| Расширение для браузера | Читает название, ссылку и цену со страницы товара, показывает список, график и фильтры |
| Локальный сервер | Хранит товары и историю цен, отдаёт их расширению через API на `http://localhost:8080/api` |

Расширение не ходит ни на какие сторонние серверы. Оно общается только с вашим локальным API.

## Установка

### 1. Запустите сервер

```bash
# замените на команду запуска вашего бэкенда
./mvnw spring-boot:run
```

Сервер должен слушать порт `8080`. В базе должны быть магазины с типами парсеров `WILDBERRIES`, `OZON`, `LETU`.

### 2. Установите расширение

1. Откройте `chrome://extensions`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку с расширением.

### 3. Пользуйтесь

1. Откройте страницу товара на Wildberries, Ozon или Л'Этуаль.
2. Нажмите иконку расширения.
3. Нажмите **Добавить товар с открытой страницы**.
4. Задайте целевую цену, если хотите.

Если товар уже в списке, повторное нажатие запишет новую цену в историю.

## Честно об ограничениях

- Трекер знает только те цены, которые вы сами записали. Задним числом историю он не восстановит.
- Цена на странице может зависеть от региона, аккаунта, карты лояльности и времени суток. Трекер фиксирует то, что увидели вы.
- Вёрстка магазинов меняется. Если парсер перестал находить цену, откройте issue.
- Проект не связан ни с одним из магазинов и не является их продуктом.
